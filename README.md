## Git basics (cheat sheet)

| Command | What it does |
| --- | --- |
| `git clone <url>` | Download a copy of a repository to your computer |
| `git status` | Show which files changed since the last commit |
| `git add <file>` | Stage a file: mark it to be included in the next commit |
| `git commit -m "message"` | Save a snapshot of the staged files, with a short note |
| `git push` | Upload your commits to GitHub |
| `git pull` | Download commits others (or you, elsewhere) pushed to GitHub |
| `git switch -c <name>` | Create a new branch, a separate line of work |
| `git log --oneline` | List past commits |
